# SPARK Store Website

A responsive front-end shoe shop made with HTML, CSS, and JavaScript.

## Open in VS Code

1. Download and unzip `spark_store_website.zip`.
2. Open VS Code.
3. Click **File > Open Folder**.
4. Choose the `spark_store_website` folder.
5. Open `index.html`.
6. Install the **Live Server** extension in VS Code.
7. Right-click `index.html` and select **Open with Live Server**.

You can also double-click `index.html`, but Live Server is better.

## Files

- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — products, search, filters, cart, and newsletter
- `assets/reference.webp` — your uploaded design reference

## Change products

Open `script.js` and edit the `products` array near the top.

## Important

This is a front-end demo. The cart works in the browser and saves with localStorage, but real checkout, payment, login, and database features need a backend or a service such as Firebase/Supabase.
